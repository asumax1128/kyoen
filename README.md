# 共円（きょうえん）

格子点に石を置き合い、**4つの石が同一円周上（または一直線上）に並んだら指摘する**数学ゲーム「共円」のブラウザ版です。
インストール不要で、PC・タブレット・スマートフォンのブラウザからそのまま遊べます。

> デモ版です。オンライン対戦（ルームを作る／参加する）は準備中です。

## 遊べるモード

| モード | 内容 |
| --- | --- |
| 1人で練習する | CPUと対戦（CPU 1〜4人、難易度3段階）。危険度マップで「置くと共円ができるマス」を色で確認できます |
| 友人と対戦する | 1台の端末を回して2〜5人で対戦。対局後は「同じ設定で再戦する」ですぐに次の対局へ |
| 問題モード（詰め共円） | 共円になっている4点を見つけて指摘する問題と、安全に置けるマスを探す問題 |

## ルール

### メジャールール
- 順番に格子点へ石を置く
- 直前の一手が、盤上の別の3つの石と同一円周上（または一直線上）に並んだら、次の石が置かれる前に指摘できる
- 指摘が正しければ、その手を打った人が脱落。最後の1人が勝ち

### 南稜ローカルルール
- 自分の番でなくても、直前の一手に限らず、盤上のどの4点でも気づいた時点で指摘できる
- 指摘が正しければ**指摘した人の勝ち**、間違っていれば**指摘した人が脱落**
- 直前に石を置いた本人はその手を指摘できない

共通の設定として、盤面の大きさ（9×9／11×11／15×15）と持ち時間（制限なし／15秒／30秒／60秒）を選べます。時間切れの場合は空いているマスに自動で石が置かれます。

## 対局後の振り返り
- **リプレイ**：1手ずつ再生して、どの時点で共円ができていたか確認できます
- **見逃された共円**：誰にも指摘されなかった共円を、盤面上に1組ずつ描いて表示します

## 公開方法（GitHub Pages）
1. このフォルダの中身（`index.html`・`README.md`・`.nojekyll`）を GitHub のリポジトリにアップロード
2. リポジトリの **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」、**Branch** を `main` ／ `/(root)` にして **Save**
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 技術メモ
- 1つの HTML ファイルで完結（React 18・Tone.js を CDN から読み込み）
- 共円の判定は4×4行列式による整数演算なので、誤差なく厳密に判定します
- 効果音は Tone.js で合成しており、音源ファイルは不要です（画面の「音ON／OFF」で切り替え）
